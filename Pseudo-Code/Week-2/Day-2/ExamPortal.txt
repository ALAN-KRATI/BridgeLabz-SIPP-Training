Pseudo-code: Online Exam Portal

1. Define class User with attributes: username, password
2. Define method login() in User
3. Define subclass Student extending User
   a. Override login()
   b. Check if student credentials are valid
   c. Check if student is enrolled in a course
   d. If valid, show exams
4. Define subclass Admin extending User
   a. Override login()
   b. Verify admin credentials
   c. If valid, show exam management tools
5. Main program:
   a. Input username and password
   b. Determine if user is Student or Admin
   c. Call respective login()
